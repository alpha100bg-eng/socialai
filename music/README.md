# 🎵 Musiques pour les vidéos

Dépose ici des fichiers musique **libres de droits** (`.mp3`, `.m4a`, `.wav`...).
Le robot GitHub Actions en choisit **une au hasard** et la colle sur chaque vidéo
(gratuitement, via ffmpeg).

## Organisation

- `music/` → musiques utilisées pour **toutes** les niches par défaut
- `music/animals/`, `music/motivation/`, etc. → musiques **spécifiques** à une niche
  (si le dossier de la niche contient des fichiers, ils sont prioritaires)

## Où trouver des musiques libres de droits (gratuit, usage commercial OK)

- **Pixabay Music** : https://pixabay.com/music/  (gratuit, sans attribution)
- **YouTube Audio Library** (depuis YouTube Studio)
- **TikTok Commercial Music Library**

➡️ Télécharge 3 à 5 morceaux que tu aimes, dépose-les ici, puis commit/push.
Plus il y en a, plus il y a de variété.
